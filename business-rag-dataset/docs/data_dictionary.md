# Data dictionary

- `id`: Stable unique record or question identifier.
- `type`: One of note, meeting_minutes, chat_message, project_update, policy, customer_update or url.
- `department`: Owning Meridian department.
- `title`: Human-readable record title.
- `date`: ISO publication or event date.
- `author`: Fictional record author.
- `content`: Complete fictional note or simulated webpage content.
- `tags`: Search metadata.
- `source_url`: Fictional URL for URL records; null otherwise.
